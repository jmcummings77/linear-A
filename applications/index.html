What the axes mean
We center the points and form the 2×2 sample covariance using division by n−1. Its symmetric eigendecomposition gives the principal directions and variances. The first component maximizes projected variance. Direction signs are arbitrary; tied eigenvalues have no unique principal direction. A collapsed cloud has zero variance, so its explained-variance percentage is undefined.

How the fit is computed
The design matrix uses columns 1, t, t², t³ with t=x/5. Column-pivoted Householder QR solves for the coefficients without forming normal equations. A rank-deficient design is rejected. RMSE describes training residuals, not prediction uncertainty; more polynomial terms can overfit. R² is undefined when all observed y values are equal.

Rank, storage, and numerical limits
The WebAssembly SVD API factors the image directly as A = UΣVᵀ using one-sided Jacobi rotations. The rank-k reconstruction retains the first k terms of UΣVᵀ. It supports zero and rank-deficient images without forming a Gram matrix. Tiny singular values still have floating-point accuracy limits; singular-vector signs and bases for repeated values are not unique.
Errors are measured before display values are clipped to [0,1]. The storage comparison counts k(2n+1) floating-point scalars for U, singular values and V, versus n² matrix entries. It is not a PNG/JPEG file-size estimate; high ranks can use more scalars than the original. No compressed file is produced.
